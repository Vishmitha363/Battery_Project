⚖ Equalization Settings

Configure balancing thresholds and protection limits — the BMS keeps running in the background

Equilibrium Limit Voltage

Equalizing Starting Voltage

Cells above this voltage trigger active balancing

Equalizing Differential Voltage

Warns when the gap between highest and lowest cell exceeds this

Equalizing Current

Bleed current used while actively balancing cells

Balancing ON Time

How long the balancer runs before a rest, per cycle (used for the completion estimate)

Balancing OFF Time

Rest gap between balancing runs, per cycle (used for the completion estimate)

Over-Balance Warning Limit

Warn when a cell's charge or discharge count reaches this many

String Number

Number of cells in series — updates the dashboard grid

Monomer Over Voltage Protection

Above this, the cell trips and charging is disabled until it recovers

Monomer Over Voltage Recovery

After a trip, voltage must drop below this before charging resumes

Single Under Voltage Protection

Below this, the BMS disconnects the cell to prevent damage

Differential Pressure Protection

Trips on excessive cell swelling / gas pressure
